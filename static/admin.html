🔍 Удаление прокси по фильтру

Удаляет все прокси, соответствующие фильтрам. Например, чтобы снести все прокси с указанным доменом — введите его в поле ниже. После удаления система немедленно запустит сбор новых прокси.

⚡ Принудительное обновление прокси

Немедленно запускает пайплайн сбора и проверки прокси, не дожидаясь планового интервала (~2.5 мин). Используйте после массового удаления прокси, чтобы система сразу нашла замену.

🗑️ Очистка мёртвых прокси

Удаляет «мёртвые» прокси (is_alive=FALSE), которые не обновлялись дольше указанного числа дней. Живые прокси не затрагиваются.

🧹 БД Render Free

Показывает размер базы, самые тяжёлые таблицы и записи, которые можно удалить без потери текущих аккаунтов.
